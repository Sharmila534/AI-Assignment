Concept Overview

1. Game State Representation

The game board is represented as a 1D array of 9 cells. Each cell contains X, O, or null.

2. Terminal States

  • Win: Three same symbols in a row, column, or diagonal
  • Lose: Opponent wins
  • Draw: Board full, no winner

3. Minimax Algorithm

Minimax recursively explores all possible future game states and assigns scores:

  • AI win → +10
  • Human win → -10
  • Draw → 0

The AI always selects the move that maximizes its minimum gain.
